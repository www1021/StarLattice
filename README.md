# 易师训 Zhijiaoxun

面向师范生教学能力成长的多智能体实训平台 —— 从对话开始训练，从证据形成成长。

## 项目简介

易师训以师范生真实教学过程为训练对象，通过多智能体技术串联「教案 — 说课 — 模拟课堂 — 实习反思」全链路实训。每一次训练都会产生结构化数据，每一份数据都沉淀为可追溯的成长证据，实现「可复现、可汇聚、可复盘」的教学能力培养闭环。

## 核心功能

- 模拟课堂：多智能体学生实时参与课堂，支持跑题、插嘴、纪律等课堂事件的触发与处理，教师以真实输入完成事件闭环；系统提供拟稿预览、点名路由与控场提醒，坚持「系统不替教师发言」的交互原则。
- 说课训练：阶段结构检测，研究员、教研员、专家多角色提问，追问应答与答辩，自动生成训练报告。
- 教案模块：教案生成、诊断、优化与 docx 导出全闭环。
- 实习反思：基于课堂观察证据的反思生成、诊断与优化。
- 成长档案与看板：汇聚四类训练，自动生成多维度诊断报告（提问、语言、控场、应变、公平等维度），形成成长趋势。
- 知识库：课件与文档上传、检索与引用。
- 易班生态联动：易班优课、易班实践、易班社群的场景接入展示。

## 技术栈

- 前端：React 19 + Vite 6 + TypeScript
- 后端：Express 5 + TypeScript（tsx watch 热更新）
- 实时通信：WebSocket
- 存储：better-sqlite3 本地数据库
- AI 能力：接入多家大模型与语音服务（通义千问、MiniMax、小米 MIMO、腾讯 IMA、讯飞语音等），按需配置。

## 快速开始

环境要求：Node.js 18+。

```bash
npm install
cp .env.example .env   # 按需填写模型服务的 API Key
npm run dev
```

启动后：

- 前端：http://127.0.0.1:5173
- 后端：http://127.0.0.1:8787
- 健康检查：GET /api/health

## 目录结构

```
src/          前端页面与组件（React + TypeScript）
server/       后端服务（Express + TypeScript）
docs/         需求文档与设计文档
data/         本地数据库目录（运行时自动生成，不入库）
generated/    训练成果导出目录（运行时自动生成，不入库）
```

## 说明

- `.env` 包含模型服务密钥，不随仓库分发，请从 `.env.example` 复制生成。
- 构建产物可通过 `npm run build` 重新生成。
