## 主演示课题

固定课题：初中数学《分数的意义》。

选择理由：

| 维度 | 说明 |
|---|---|
| 代码默认适配 | 虚拟课堂默认学科接近数学场景，学生 Agent 容易产生差异化回应 |
| 概念误区清晰 | “平均分”“单位 1”“随便分成四块是否表示四分之一”适合触发追问和纠错 |
| 链路表达完整 | 可串联知识库资料、教案、说课、模拟课堂、实习反思和成长档案 |
| 国赛展示友好 | 课题基础、可视化强，评委能快速理解训练价值 |

推荐主演示输入：

```text
请以初中数学《分数的意义》为课题，帮我完成一次师范生实训：
1. 先结合知识库资料梳理教学重点和学生误区；
2. 生成 1 课时教案并诊断；
3. 完成一段说课训练；
4. 进入模拟课堂，围绕“平均分”和“单位 1”提问；
5. 生成课堂诊断、实习反思，并沉淀到成长档案。
```

课堂发言脚本：

```text
请同学们把一个圆平均分成四份，涂出其中一份。
想一想：为什么它可以表示四分之一？
如果只是随便分成四块，还能不能叫四分之一？请说明理由。
```
