## 虚拟课堂完整演示流程（定稿）

录前准备：服务为最新代码；浏览器硬刷新；配置默认（数学/初中/分数的意义/普通班/提问训练/普通/综合训练）；点「生成虚拟课堂」开新场；三句手打话术备剪贴板。

1. 生成课堂（3s）：六张学生卡，五类人设各一。口播：系统生成五类学生画像的虚拟班级。
2. 手打第一句发送（4s）：两名学生出声回答，其余卡片同步听讲反应。
3. 手打第二句发送（4s）：仅赵明轩回答并暴露误区，wrong_answer 事件。口播：点名谁谁答，误区被事件 Agent 捕获。
4. 手打第三句发送（5s）：赵明轩解释 + 调皮生苹果跑题，off_topic 警示弹出、「提醒全班回到任务」浮现。口播：跑题被实时检测，系统给出情境化控场建议。
5. 点「提醒全班回到任务」（4s）：草稿进输入框，确认发送，事件已处理。口播：教师确认草稿发送，事件闭环。
6. 选基础薄弱型学生点「点名回答」（4s）：草稿发送后该生部分回答。
7. 点「进入课堂小结」（3s）：草稿发送，阶段进入总结。
8. 「结束训练并生成报告」（5s）：自动滚到报告；特写总分、事件复盘（双事件已处理）、证据链、Word 成果。口播：每一条评分都能回溯到课堂原话。

剪辑：课堂段压 20s 时剪掉 6、7 步或加速，保 2-5 与 8。应急：模型不稳规则 fallback 接管；拍坏重新生成课堂再拍；「追问理由」留答辩现场演示。
