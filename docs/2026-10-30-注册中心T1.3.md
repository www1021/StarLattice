# T1.3 Agent / Tool Registry

目标：把「有哪些 Agent、各自能做什么、能调哪些工具」从散落在课堂代码里的隐式约定，变成可查询、可扩展的注册中心，供工作流、调度器和前端共用。

## 交付内容

| 能力 | 实现位置 |
|---|---|
| Agent 种子（11 个） | `server/platform/registry/agents.ts` 的 `BUILTIN_AGENTS` |
| 工具种子（7 个，builtin/mcp/http） | `server/platform/registry/tools.ts` 的 `BUILTIN_TOOLS` |
| 写入校验（id、权重、type、schema） | `parseAgentWrite()` / `parseToolWrite()` |
| 启动注册（幂等，不覆盖手工修改） | `PlatformStateStore.seedAgents()` / `seedTools()`；`routes.ts` 的 `seedRegistry()` |
| 列表 / 详情 / 新增更新 | `platform_agents`、`platform_tools` 的 `list/get/save` |
| 汇总（角色分布、工具类型分布） | `PlatformStateStore.registrySummary()` → `/api/platform/health.registry` |
| 前端类型与 API 封装 | `src/features/platform/types.ts`、`src/features/platform/api.ts` |

## 接口

```http
GET  /api/platform/agents            → { agents, total }
GET  /api/platform/agents/:id        → { agent } | 404
POST /api/platform/agents            → 201 新建 / 200 更新 { agent, created }
GET  /api/platform/tools             → { tools, total }
GET  /api/platform/tools/:id         → { tool } | 404
POST /api/platform/tools             → 201 新建 / 200 更新 { tool, created }
```

```json
// POST /api/platform/agents
{
  "id": "demo-critic-agent",
  "name": "试讲挑错 Agent",
  "role": "教研评审",
  "prompt": "只指出最影响课堂效果的一个问题。",
  "tools": ["classroom.simulate"],
  "capabilities": [{ "tag": "挑错", "weight": 0.88 }],
  "memory": { "scope": "run" }
}
```

规则：

- `id` 只允许字母、数字、下划线、短横线；`name` 必填。
- `capabilities[].weight` 必须在 0–1；`memory`、`schema` 必须是对象。
- 工具 `type` 只允许 `builtin / mcp / http`。
- 更新时省略 `version` 自动 +1；省略 `role/prompt/tools/model/capabilities/memory` 保留原值，显式传空可清空。
- 种子只 `INSERT OR IGNORE`：手工改过的 Agent 不会被重启覆盖，自定义 Agent 也不会被删除。

## 验收记录

环境：隔离栈 `PORT=8899 PLATFORM_DB_PATH=/tmp/yiban-t13/platform.db`，全新库启动。

1. `GET /api/platform/health` → `registry.agentCount = 11`、`toolCount = 7`，`toolsByType = { builtin: 5, mcp: 1, http: 1 }`，`agentsByRole` 含「虚拟学生: 5」。

5. 非法 Agent（`id = "bad id"`）→ 400；非法工具（`type = "grpc"`）→ 400；不存在的 id → 404。
6. `POST /api/platform/tools` 新建 `tts.speak` → 201；工具数 8。
7. 重启同一数据库 → `seededRegistry = { agents: 0, tools: 0 }`，总数仍为 12 / 8，自定义记录保留，证明种子幂等。

## 已知边界

- 本任务只做注册与 API；注册中心页面（列表、版本、能力标签、被调用次数）属于 T1.13。
- 工作流编译阶段尚未强制校验 Agent/Tool 是否已注册，当前由测试兜底；等 T1.9 统一 API 层时再考虑把校验挂到编译器。
- 还没有「每个 Agent 被调用次数」的统计，需要执行器在 T1.8 指标采集时回写。
- 能力权重未参与调度，T1.5 会用它计算「能力匹配度」。
- `lms.publish` 是 HTTP 类型示例，未真实接入，默认 `enabled = false`。
