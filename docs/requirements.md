# StarLattice 需求文档

## 1. 文档信息

- 项目名称：“StarLattice”——面向师范生教学能力成长的多智能体实训平台
- 项目类型：易班智能体 AIGC 应用
- 当前版本：国赛功能完善版
- 文档目标：为 AI 辅助开发、功能验收、测试数据准备和国赛作品交付提供统一需求基线
- 目标交付时间：2026-07-31 完成功能冻结与测试数据沉淀

## 2. AI 开发流程

本项目后续开发按以下流程推进：

1. 需求澄清：明确用户、场景、核心任务、验收标准和优先级。
2. 任务拆解：将需求拆为可由 AI 编程逐项实现的功能任务。
3. 设计先行：先确认数据结构、接口、Agent 协作和页面交互，再编码。
4. 小步实现：每次只实现一个闭环或一个明确修复点。
5. 自动验证：每次改动后至少执行构建、关键接口测试和主流程手动测试。
6. 数据沉淀：真实记录测试输入、输出、耗时、评分、引用数、导出结果。
7. 回归冻结：7 月 31 日后只修致命缺陷，不再新增大功能。

## 3. 项目背景

师范生从课程学习走向真实课堂时，常见问题包括：

- 教案设计模板化，教学目标、活动和评价缺少一致性。
- 说课训练不足，答辩追问和教学理论表达薄弱。
- 模拟授课缺少即时反馈，难以暴露课堂互动、控场和应变问题。
- 教育实习反思容易停留在流水账，缺少证据、原因分析和改进闭环。
- 单次训练结果分散，难以形成可追踪的教学能力成长档案。

StarLattice定位为师范生教学能力成长实训平台，通过多智能体协作，将“备课、说课、试讲、实习反思”转化为可反馈、可复盘、可持续改进的训练闭环。

## 4. 产品定位

StarLattice不是教案代写工具，也不是普通聊天机器人，而是：

- 师范生的教学训练伙伴。
- 指导教师的过程证据助手。
- 易班智能体赛道的多智能体教育实训应用。
- 面向教师教育数字化的成长档案平台。

核心产品心智：

> 从对话开始训练，从证据形成成长。

## 5. 用户与角色

### 5.1 师范生

目标：

- 快速完成教案初稿并获得诊断。
- 进行说课、答辩和模拟课堂训练。
- 整理实习日志与反思。
- 查看阶段成长档案。

痛点：

- 不知道教案哪里不合格。
- 说课逻辑和理论依据薄弱。
- 缺少真实课堂前的安全练习环境。
- 反思缺少证据和改进方向。

### 5.2 指导教师

目标：

- 查看学生训练过程和能力变化。
- 依据证据进行指导。
- 判断学生是否形成持续改进闭环。

痛点：

- 学生训练材料分散。
- 单次评分难以说明成长过程。
- 缺少可追溯证据链。

### 5.3 易班赛事评委

目标：

- 判断作品是否体现真实高校场景。
- 判断是否具有智能体协作创新。
- 判断是否有测试数据、应用入口和可推广价值。
- 判断是否服务网络育人和易班生态。

关注点：

- 应用场景是否明确。
- 功能是否完整可演示。
- 多智能体是否真实参与决策。
- 测试数据和预期结果是否可信。
- 易班优课、易班实践、易班社群联动是否清楚。

## 6. 当前已完成能力

当前代码已具备以下基础能力：

- React/Vite 前端应用和 Express 后端服务。
- 新对话入口和文件上传。
- 教案生成、诊断、优化和导出。
- 说课训练，包含阶段追踪、角色 Agent 评价、追问、答辩题和报告。
- 虚拟课堂，包含教师行为分析 Agent、学生 Agent 群体、课堂事件 Agent、课堂观察员 Agent、评价报告 Agent。
- 实习反思生成、证据归纳、优化和导出。
- 本地知识库，支持 PDF、TXT、Markdown、CSV、JSON 等资料上传和检索。
- IMA 知识库连接测试、同步和检索预留。
- 历史训练记录、评价记录和 SQLite 存储。
- 成长档案，包含训练分布、能力矩阵、证据时间线、代表成果和导出。
- 智能体运行看板，包含 Agent 激活、事件触发、观察建议、证据链等统计。
- 演示数据 seed 接口。
- 构建验证已通过。

## 8. 核心业务闭环

### 8.1 总闭环

1. 师范生创建训练任务。
2. 选择或上传知识库资料。
3. 完成教案、说课、模拟课堂或实习反思训练。
4. 系统生成评价、证据链、改进建议和成果文件。
5. 训练结果进入历史记录。
6. 成长档案汇总阶段能力变化。
7. 智能体看板展示 Agent 协作证据。
8. 易班生态模块展示资源、实践和社群联动。

### 8.2 国赛主演示链路

推荐使用固定课题：初中数学《分数的意义》。

流程：

1. 上传课程标准或课例资料到知识库。
2. 生成教案初稿。
3. 查看教案诊断并优化。
4. 进入说课训练，完成片段说课并回答专家追问。
5. 进入虚拟课堂，教师讲解、提问、追问、控场、总结。
6. 生成课堂诊断报告。
7. 生成实习反思或课堂复盘。
8. 查看成长档案和智能体看板。
9. 展示易班优课、易班实践、易班社群联动。

## 9. 功能需求

### 9.1 新对话与任务识别

需求：

- 用户可通过自然语言发起训练任务。
- 系统可识别训练类型：教案诊断、说课陪练、模拟课堂、实习反思。
- 用户可上传文本、PDF、图片等资料作为输入。
- 对话结果可保存为训练记录。

验收标准：

- 输入“帮我生成初中数学分数的意义教案”时，能进入教案任务。
- 输入“我要练习说课”时，能进入说课任务。
- 输入“帮我整理实习反思”时，能进入反思任务。
- 文件上传失败时有明确错误提示。

优先级：P1

### 9.2 教案生成与诊断

需求：

- 支持输入学科、年级、课题、课时、教材背景、学情、训练目标。
- 支持选择知识库资料作为生成依据。
- 生成结构化教案，包括教学目标、学情分析、重难点、教学准备、教学过程、提问预设、板书、作业、反思建议、师德育人融入点。
- 自动诊断教学目标、学情分析、活动流程、课堂互动、反思改进、师德育人等维度。
- 支持根据诊断建议生成优化稿。
- 支持导出 Markdown 或 Word 成果。
- 优化结果进入历史记录和成长档案。

验收标准：

- 完成“生成 -> 诊断 -> 优化 -> 导出”闭环。
- 每份诊断包含总体分、维度分、问题、建议和下一步任务。
- 知识库引用数能被记录。
- 至少完成 5 组教案测试数据。

优先级：P0

### 9.3 说课陪练

需求：

- 支持文字输入、浏览器语音或讯飞语音输入。
- 按说教材、说学情、说目标、说重难点、说方法、说过程、说活动、说评价、说板书、说反思进行阶段追踪。
- 自动标注缺失环节、逻辑断点、表达风险和术语问题。
- 研究员 Agent、教研员 Agent、专家 Agent 分别给出评价。
- 支持中断追问和答辩题生成。
- 支持用户回答追问并获得评分。
- 生成说课训练报告。
- 结果进入历史记录和成长档案。

验收标准：

- 完成“说课输入 -> 阶段检测 -> 专家追问 -> 回答评分 -> 报告生成”闭环。
- 至少生成 3 类角色评价。
- 至少生成 1 个追问和 1 个答辩题。
- 至少完成 5 组说课测试数据。

优先级：P0

### 9.4 模拟课堂

需求：

- 支持配置学科、年级、课题、班级类型、训练目标、难度和专项训练模式。
- 生成包含学霸型、基础薄弱型、沉默型、调皮型、误解型的学生 Agent 群体。
- 教师输入讲解、提问、追问、反馈、控场、总结等课堂行为。
- 教师行为分析 Agent 判断课堂阶段、行为类型、难度、清晰度、问题类型、预期答案和常见误区。
- 学生 Agent 根据画像、问题和课堂状态生成差异化回应。
- 课堂事件 Agent 捕捉错误答案、无人回应、跑题、进度风险和纪律问题。
- 课堂观察员 Agent 给出实时建议。
- 支持点名、追问、小组活动、暂停控场、压缩总结等课堂操作。
- 生成课堂报告，包含总分、维度分、事件复盘、优势、问题、建议、证据链、Agent 决策依据、协作过程和下一轮训练任务。
- 报告进入历史记录和成长档案。
- 提供演示数据和 fallback，保证现场稳定。

验收标准：

- 连续完成 5 轮课堂互动不报错。
- 至少 4 类课堂事件可触发。
- 至少 3 类课堂事件可被教师行为处理。
- 报告至少包含 3 条证据链。
- 学生回答明显贴合当前课题。
- 至少完成 5 组模拟课堂测试数据。

优先级：P0

### 9.5 实习反思

需求：

- 支持输入或上传实习日志、听课记录、课堂事件和图片/文本材料。
- 自动提取实习证据。
- 生成结构化反思，包括事件描述、问题分析、理论依据、改进策略和后续行动。
- 诊断反思是否具有证据、原因分析、理论连接、改进闭环和师德育人意识。
- 支持根据诊断建议优化反思。
- 支持导出成果。
- 支持关联前序教案、说课和模拟课堂薄弱项。
- 结果进入历史记录和成长档案。

验收标准：

- 完成“证据输入 -> 反思生成 -> 诊断 -> 优化 -> 导出”闭环。
- 每篇反思至少包含 3 条证据。
- 反思中能出现改进策略和下一次行动。
- 至少完成 5 组实习反思测试数据。

优先级：P0

### 9.6 知识库与 RAG

需求：

- 支持创建本地知识库。
- 支持上传 PDF、TXT、Markdown、CSV、JSON。
- 自动切分知识片段并建立检索。
- 支持在教案、说课、反思和通用对话中选择知识库。
- 返回引用片段、来源文档和相似度分数。
- 支持 IMA 知识库连接测试、同步和检索。

验收标准：

- 上传课程标准 PDF 后能检索到相关片段。
- 生成教案时能展示引用来源。
- IMA 未配置时有明确状态提示。
- 知识库引用数进入测试数据表。

优先级：P0

### 9.7 成长档案

需求：

- 汇总教案诊断、说课陪练、模拟课堂、实习反思四类训练。
- 展示训练次数、平均得分、薄弱维度、推荐下一步任务。
- 展示能力成长矩阵。
- 展示训练证据时间线。
- 展示代表性成果。
- 展示实习反思成长摘要。
- 展示智能体协同数据。
- 展示易班生态联动。
- 支持导出 Markdown 和 Word。

验收标准：

- 完成四类训练后，成长档案能全部反映。
- 能导出成长档案。
- 能说明学生阶段成长变化和下一步任务。

优先级：P0

### 9.8 智能体看板

需求：

- 展示学生 Agent 激活次数。
- 展示课堂事件 Agent 触发次数。
- 展示观察员建议数量。
- 展示证据链数量。
- 展示事件处理率。
- 展示四类训练能力画像。
- 展示多智能体协作流程。
- 提供生成演示数据入口。

验收标准：

- 点击生成演示数据后看板有可展示数据。
- 看板能解释系统不是单轮问答，而是多 Agent 协作。
- 看板数据与成长档案一致。

优先级：P0

### 9.9 易班生态联动

需求：

- 易班优课：作为课程标准、优秀课例、教师教育资料来源展示。
- 易班实践：将成长档案模拟同步为实践记录或实践学分依据。
- 易班社群：展示优秀教案、说课片段、实习反思的社群互评入口。
- 明确每个联动项状态：本地演示、预留接口、可扩展接入。

验收标准：

- 成长档案中显示易班生态联动项。
- 系统内能解释每个联动项如何服务网络育人。
- PPT 和演示可直接引用系统截图。

优先级：P0

### 9.10 测试数据

需求：

- 7 月 31 日前完成不少于 20 组测试数据。
- 每个核心模块不少于 5 组。
- 每组测试记录输入、输出摘要、训练类型、评分、耗时、知识库引用数、是否导出成功、问题记录。
- 形成可用于国赛答辩的数据结论。

验收标准：

- 测试数据表不少于 20 行。
- 导出成功率有统计。
- 平均生成耗时有统计。
- 训练前后或优化前后评分变化有统计。

优先级：P0

## 10. 非功能需求

### 10.1 稳定性

- 核心演示链路连续运行不崩溃。
- API 不可用时有 fallback 或清晰错误提示。
- 模拟课堂演示至少连续 5 轮不报错。

### 10.2 可解释性

- 评价结果必须能追溯到训练证据。
- Agent 决策依据必须可展示。
- 成长档案必须展示证据时间线，而不是只有分数。

### 10.3 性能

- 普通文本训练响应建议控制在 15 秒内。
- 文件上传限制应提示清楚。
- 构建产物可接受当前体积，但后续可考虑代码分包。

### 10.4 安全

- 不得提交 `.env` 和真实 API Key。
- 提交包只包含 `.env.example`。
- 用户上传内容仅用于本地演示和训练，不在文档中暴露个人隐私。

### 10.5 可维护性

- 新增功能应优先复用现有服务：lessonPlanService、speakTrainingService、classroomService、internshipReflectionService、knowledgeService、chatRepository。
- 不为国赛临时堆 UI，优先强化已有闭环。
- 每个 Agent 的输入、输出和职责要保持清晰。

## 11. 数据指标

国赛功能冻结时应至少具备以下指标：

- 测试样例数：不少于 20 组。
- 教案测试：不少于 5 组。
- 说课测试：不少于 5 组。
- 模拟课堂测试：不少于 5 组。
- 实习反思测试：不少于 5 组。
- 完整链路测试：不少于 2 组。
- 导出成功率：目标 95% 以上。
- 模拟课堂事件处理率：演示样例目标 70% 以上。
- 知识库引用覆盖：至少 8 组样例使用知识库引用。
