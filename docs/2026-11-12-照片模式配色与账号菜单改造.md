# 照片模式配色与账号菜单改造

上一版把面板底色全撤了（`--panel-alpha: 0`）。实际用起来发现另一个问题：深色主题下，工作台、MCP、场景验证这些页面的卡片仍然是 `--n-99` 那块近黑的实底，照片只露在卡片缝里，看着像一块黑板压在图上。这一版把照片模式的配色整套重做。

## 做了什么

### 1. 卡片换成照片同色系的半透明膜

关键是不再让主题决定卡片颜色。做法分两步：

- 机械替换：`styles.css` / `theme.css` / `platform.css` / `settings.css` 里，所有 `background` / `border` / `box-shadow` / `fill` 声明中的 `var(--n-XX)` 换成 `--surf-XX` / `--line-XX`（共 682 条声明）。这两个新变量默认就是 `var(--n-XX)`，所以没有照片时视觉零变化。
- 照片模式下把它们统一映射到 `rgba(var(--photo-tint), a)`，浓度按档位从 0.46 递减到 0.22（描边 0.36 递减到 0.2）。`--rgb-surface` 也指向 `--photo-tint`，`--panel-alpha` 从 0 回到 0.82。

膜的颜色就是从照片里取出来的主色，半透明叠在原图上，跟背景同色，但遮掉了细节、还留一圈淡边，所以看得出是个框。不会是纯黑，也不会是白板。

`photoTone.ts` 负责取色：把图缩到 64×64，算线性亮度，`< 0.3` 判暗照片；按亮度排序后截一段主体区（暗图 20%~48%、亮图 40%~68%）求均值，往灰里收 24%，再按明暗轻微提亮。结果缓存在 Map 里，同一张图只算一次。`applyAppearance` 异步取色，先给一个主题兜底色，取完再替换；用递增 token 防止旧照片的结果盖到新照片上。

### 2. 主题与背景照片互斥

`html[data-photo="on"][data-photo-ink="light|dark"]` 这组选择器特异性 (0,3,0)，高于 `theme-tokens.css` 里的 `:root[data-theme="dark"]` (0,2,0)，所以照片模式下直接把整套 `--n-*` 字色阶梯翻面：

- 暗照片 → 亮字（复用深色主题的字色阶梯），黑雾托字
- 亮照片 → 暗字（复用白主题的字色阶梯），白雾只留一圈贴边

用户当前选白还是黑，对照片模式没有任何影响。另外中和了几条按 `data-theme` 改观感的残留规则：图片 `brightness(.92)`、画布圆点颜色、滚动条、玻璃高光。

设置面板里，有照片时两张主题卡置灰不可选，并写明「背景照片已接管配色」。移除照片会回到上次选的主题（theme 值一直保留，没有清掉）。

### 3. 侧栏改成一层膜

原来是系统给的灰实底。现在 `html[data-photo="on"] .sidebar` 用照片主色的渐变膜（左 0.64 / 右 0.48），右边留一道 `0.42` 的淡边和一点投影，左右分区看得出来，照片仍能透出。收起态给 0.66 的实膜，图标立得住。

### 4. 设置并入用户区

侧栏底部原来并排「设置」+ 账号行，现在只剩账号行。点它从上方弹出菜单（挂到 `body` 上，避开侧栏 overflow），三项：

- 设置 → 设置弹窗「外观」页
- 模型与密钥 → 设置弹窗「模型与密钥」页
- 记忆与进化 → 跳进化页

每一项都对应真实界面，没有做「意见反馈 / 检查更新 / 退出登录」这类没有落点的假按钮。菜单支持外部点击、Escape、resize / scroll 关闭；收起侧栏后账号行收成一颗头像，仍能点开。

浮层（弹窗 / 下拉 / 菜单）在照片模式下统一换回不透明实底：页面卡片可以是膜，浮层不能透出背后的工作台，否则两层文字叠在一起。用 `:is(...)` 一次性列出 16 个浮层容器，在里面把 `--surf-*` / `--line-*` 重定义回实色 `--n-*`。

## 验证

- `tsc -b`、`tsc -p tsconfig.server.json --noEmit`、`check:encoding`、`npm run build`（20.29s）、`test:platform` 297/297 全过。
- 无头 Chrome 1440×900 实拍：暗照片下的工作台 / MCP / 场景验证 / 工作流 / 对话，亮照片下的场景验证，无照片深色主题回归，设置弹窗，账号菜单。
- CDP 探测确认：`--photo-tint: 48, 53, 60`、卡片 `rgba(48, 53, 60, 0.46)`、侧栏是照片色渐变膜；菜单三项分别落到正确页签 / 页面；主题卡 `disabled: [true, true]`；收起态菜单仍可打开。

## 已知短板

- 取色是按全图统计的，明暗跨度特别大的照片（半边天空半边阴影）仍可能让某一侧的文字偏淡，靠局部文字光晕兜底。
- 照片里有大块纯白主体时，暗字压上去无解，换图或调透明度更实际。
- 亮照片下 12px 的灰色小字对比度仍偏低，已经把 42~84 档字色压深了 5~8 个百分点。
